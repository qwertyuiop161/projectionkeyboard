# projectionkeyboard

Using a galvonometer, a laser pointer, inrfared cam, rasp pi, and infrared laser (with some power and control parts)
projects a wireframe style red static interface, and detects infrared contact
programmable using the PI
create anything from a stream deck to a full keyboard
